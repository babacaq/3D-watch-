# Mobile3D — 3D-движок для Android (C++17, OpenGL ES 3.0)

Движок **не содержит встроенных моделей**: вы импортируете свои файлы.
Поверх модели работают скелетная анимация, физика и 3D-эффекты (огонь, дым, вспышка выстрела, взрыв, искры).

## Форматы моделей

| Формат | Что поддерживается |
|---|---|
| **GLB / glTF 2.0** | меши, иерархия узлов, скины (до 64 костей на скин), анимации (перенос/поворот/масштаб, LINEAR/STEP/CUBICSPLINE), текстуры (PNG/JPEG, в т.ч. внутри GLB и data-URI), alpha mask/blend, внешние `.bin` |
| **OBJ + MTL** | позиции, нормали, UV, группы материалов, `map_Kd`, `Kd`, `Ns`, прозрачность `d` |
| **STL** | бинарный и текстовый |

* **«Prisma 3D»**: собственного формата у этого приложения я проверить не смог. Prisma 3D умеет экспортировать в **OBJ, GLB/glTF, STL** — экспортируйте в один из них.
* **FBX не поддерживается** (закрытый формат). Сконвертируйте в GLB (например, Blender или FBX2glTF).
* Картинки декодируются встроенными декодерами: PNG, JPEG (baseline + progressive), BMP, TGA. Текстуры больше 2048 px уменьшаются.

## Как загрузить модель на телефоне

1. Кнопка **OPEN** → системный выбор файлов. Выбирайте сразу **все** нужные файлы: `model.obj` + `model.mtl` + текстуры, или `model.gltf` + `model.bin` + текстуры. GLB и STL — один файл.
2. Или откройте файл через «Открыть с помощью → Mobile3D».
3. Или положите модели в `android/app/src/main/assets/models/` до сборки — они загрузятся при запуске.

Выбранные файлы копируются в папку приложения (`Android/data/dev.mobile3d.engine/files/models/…`), последние 6 моделей загружаются при следующем запуске.
Модель масштабируется до 2 м по наибольшему размеру и ставится на «землю».

## Управление

* 1 палец — вращать камеру; 2 пальца — масштаб (щипок) и высота взгляда.
* **Тап по сцене** применяет выбранный инструмент: `MUZZLE` (поставить дуло оружия), `BOX`/`BALL` (бросить физическое тело), `FIRE` (костёр с дымом и искрами), `SMOKE` (источник дыма), `BOOM` (взрыв с ударной волной).
* **SHOOT** — выстрел из точки дула вдоль оси **AIM** (±X/±Y/±Z): вспышка, дым, искры, пуля с трассером и динамическим светом.
* Кнопки клипов анимации, PAUSE/SPEED, SHADOW (тени), BONES (скелет), RESET (убрать тела и эффекты).

## Физика

Импульсная физика (sequential impulses) с шагом 1/120 с: коробки, шары, сфера/коробка/плоскость, статичная сетка из треугольников вашей модели как коллайдер, пули со «свипом» (не пролетают сквозь тонкие стенки), шарнирные соединения, засыпание островов тел, взрывные импульсы, рейкаст. 300 тел ≈ 2.2 мс на шаг (десктоп, 1 поток).

## Сборка APK

Локально нужны Android SDK + NDK 26, JDK 17, Gradle 8.7:

```
cd android
gradle assembleRelease
```

Либо без установки чего-либо: залейте папку в GitHub — workflow `.github/workflows/build-apk.yml` соберёт APK (artifact `Mobile3D-apk`). APK подписан отладочным ключом, ставится сразу (разрешите установку из неизвестных источников).

## Что проверено, а что нет

Проверено на ПК (Mesa llvmpipe, OpenGL ES 3.2): физика (9 групп тестов), импорт всех форматов и декодеры (сверка JPEG с эталоном, фаззинг под ASan/UBSan), рендер кадров: тени, текстуры, скелетная анимация, огонь/дым/вспышка/взрыв, интерфейс, тапы и кнопки.

**Не проверено**: сборка Android-части (в среде не было NDK/Gradle — код проверен только на синтаксис против заглушек заголовков) и запуск на реальном телефоне. Первая сборка в CI может потребовать мелких правок.

## Ограничения

* Интерфейс: встроенный шрифт 5×7, только английские заглавные буквы.
* Коллайдер модели строится по позе при загрузке и не следует за анимацией.
* Более 64 костей в одном скине не поддерживается; модели свыше 400 тыс. треугольников — без коллайдера.
* Вершинный шейдер использует 256 uniform-векторов для костей — на современных GPU (Adreno/Mali) достаточно.

```

tests/      physics_test, import_test, assets (тестовые файлы)
tools/      gen_test_assets.py — генерирует тестовые файлы
```
