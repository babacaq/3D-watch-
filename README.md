# PrismLab

Приложение для Android: собираете 3D-сцену из импортированных моделей, ставите камеру и свет, анимируете ключами,
добавляете эффекты (огонь, дым, вспышка выстрела, взрыв, искры) и экспортируете кадр (PNG) или ролик (MP4).

## Что умеет
- **Импорт**: OBJ (+MTL, текстуры), GLB, glTF (+BIN, текстуры; кости и клипы анимации), STL. Встроенных моделей нет.
  Не поддерживаются: `.prisma` (родной формат Prisma 3D) и FBX. Prisma 3D умеет экспортировать OBJ / GLB / glTF / STL — используйте их.
- **Сцена**: перемещение / вращение / масштаб жестом по гизмо, привязка к шагу, копирование, видимость, камеры, источники света.
- **Анимация**: ключи положения/поворота/масштаба (линейно, плавно, ступенькой), клипы из GLB с перекрёстным смешиванием, видимость.
- **Прицепить / отцепить**: предмет (например, оружие) прицепляется к объекту или кости (рука) на выбранном кадре и отцепляется на другом — предмет остаётся там, где был.
- **Эффекты** — объекты на таймлайне: огонь, дым, вспышка выстрела, взрыв, искры; симуляция детерминированная, при перемотке кадр всегда одинаковый.
- **Рендер**: HDR, PBR, мягкие тени от солнца, небесное освещение, SSAO, bloom, плёночная тональная кривая, FXAA.
  Для экспорта кадра — накопление нескольких проходов (чище тени и сглаживание).
- **Экспорт**: PNG → `Pictures/PrismLab`, MP4 (H.264) → `Movies/PrismLab`. Проекты сохраняются автоматически и вручную (`.prismlab`, JSON).

## Сборка APK (без компьютера)
Каждый push в GitHub запускает `.github/workflows/build-apk.yml`. Готовый APK лежит в Actions → последний запуск → Artifacts → `PrismLab-apk`.
Требуется Android 10+ (minSdk 29) и OpenGL ES 3.0.

## Устройство проекта
- `engine/` — ядро на C++17 (рендер, сцена, анимация, импорт, эффекты, интерфейс, приложение `App`).
- `platform/android_main.cpp` — NativeActivity + EGL; `android/app/src/main/java/...` — выбор файлов, сохранение в галерею, кодер MP4.
- `platform/app_test.cpp`, `tests/` — проверки на компьютере (Mesa, без окна): `cmake -S . -B build && cmake --build build`.
- Физика (`engine/physics.*`) осталась в коде и проверяется тестом, но в интерфейсе первой версии её нет.
