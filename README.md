# PrismLab

Приложение для Android: собираете 3D-сцену из импортированных моделей, ставите камеру и свет, анимируете ключами,
добавляете физику, кости и эффекты (огонь, дым, вспышки выстрелов, взрывы, кровь, искры) и экспортируете кадр (PNG) или ролик (MP4).

## Что умеет
- **Импорт**: OBJ (+MTL, текстуры), GLB, glTF (+BIN, текстуры; кости и клипы анимации), STL. Встроенных моделей нет.
  Не поддерживаются: проект `.proj` из Prisma 3D и FBX. В Prisma 3D выберите экспорт **glTF** (файл `.gltf` вместе с `.bin` и текстурами выбирайте одновременно) или OBJ.
- **Интерфейс**: стартовый экран с проектами (превью, дата, размер, меню ⋮), нижняя прокручиваемая панель инструментов, вертикальный и горизонтальный экран.
- **Сцена**: перемещение / вращение / масштаб жестом по гизмо, привязка к шагу, копирование, видимость, камеры, источники света.
- **Кости**: показываются только настоящие суставы (узлы с мешами, как Player1Mtl2, костями не считаются). Тап по кружку выбирает кость, и стрелки/кольца гизмо встают на неё: двигается и вращается только кость, а не всё тело. Тап мимо снимает выбор. Поза записывается ключом на таймлайн; ползунки X/Y/Z, сброс, удаление. У моделей без скина кости — узлы иерархии.
- **Физика**: твёрдые тела (коробка/шар), падение и столкновения, включение в нужный кадр, масса, упругость, трение, начальный толчок; неподвижные предметы работают как препятствия. **Рэгдолл** по костям скелета (шаровые суставы с пределом сгиба, падение с выбранного кадра, столкновение с полом и неподвижными предметами). **Инерция предмета на кости** (оружие на спине, сумка качаются при движении персонажа). **Ткань / волосы / плащ** — вершинная физика для меша без костей (закреплённый край, жёсткость, возврат к форме, гравитация, ветер). Всё запекается по кадрам и совпадает при перемотке.
- **Анимация**: ключи положения/поворота/масштаба (линейно, плавно, ступенькой; поворот интерполируется кватернионами по кратчайшему пути, ключи костей тоже). Ограничение: поворот объекта между двумя ключами не может быть больше 180° — для оборота ставьте промежуточные ключи.
- **Экспорт анимации скелета (GLB / glTF 2.0)** для Godot 4, Unity, Unreal, Blender: модель + скелет + запечённая анимация (клип, ключи костей, рэгдолл), варианты «с движением по сцене», «на месте», «только скелет». Файл сохраняется в `Загрузки/PrismLab`. Вершинная ткань в GLB не попадает.
- **Настройки и темы**: чёрная (по умолчанию), белая, GTA 6; размер элементов, чувствительность вращения вида, инерция, инверсия, двойной тап для показа объекта. Форматы кадра: вертикальный 9:16, горизонтальный 16:9, квадрат.
- **Камера окна**: плавный переход, инерция, виды (спереди/сзади/слева/справа/сверху), адаптивные ближняя и дальняя плоскости.  клипы из GLB с перекрёстным смешиванием, видимость.
- **Прицепить / отцепить**: предмет (например, оружие) прицепляется к объекту или кости (рука) на выбранном кадре и отцепляется на другом — предмет остаётся там, где был.
- **Эффекты** — объекты на таймлайне: огонь, дым, искры, вспышка выстрела (пистолет / дробовик / автомат с очередью), взрыв (сила меняет размер, дым, разлёт и толчок), кровь (брызги и течёт, капли падают по физике, пятна на полу). Эффект двигается как обычный объект, прицепляется к кости и анимируется ключами; полосу эффекта на таймлайне можно тянуть. Симуляция детерминированная.
- **Рендер**: HDR, PBR, мягкие тени от солнца (размытие растёт с расстоянием от предмета) и контактные тени, небесное освещение, SSAO, bloom, плёночная тональная кривая, FXAA.
  Для экспорта кадра — накопление нескольких проходов (чище тени и сглаживание).
- **Экспорт**: PNG → `Pictures/PrismLab`, MP4 (H.264) → `Movies/PrismLab`, GLB → `Загрузки/PrismLab`. Проекты сохраняются автоматически и вручную (`.prismlab`, JSON).

## Сборка APK (без компьютера)
Каждый push в GitHub запускает `.github/workflows/build-apk.yml`. Готовый APK лежит в Actions → последний запуск → Artifacts → `PrismLab-apk`.
Требуется Android 10+ (minSdk 29) и OpenGL ES 3.0.

## Устройство проекта
- `engine/` — ядро на C++17 (рендер, сцена, анимация, импорт, эффекты, интерфейс, приложение `App`).
- `platform/android_main.cpp` — NativeActivity + EGL; `android/app/src/main/java/...` — выбор файлов, сохранение в галерею, кодер MP4.
- `platform/app_test.cpp`, `tests/` — проверки на компьютере (Mesa, без окна): `cmake -S . -B build && cmake --build build`.
- `engine/physics.*` — физический движок; `engine/app_home.cpp` — стартовый экран; `engine/app_panels.cpp` — вкладки «Кости», «Физика», «Эффекты»; `engine/scene_sim.cpp` — рэгдолл, инерция предметов, ткань; `engine/glb_export.cpp` — экспорт GLB; `engine/app_settings.cpp` — настройки и темы.
